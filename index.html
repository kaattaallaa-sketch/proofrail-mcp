ProofRail checks MCP protocol negotiation, tools/list, tool schemas, Streamable HTTP transport and authentication classification. It returns PASS, FAIL or PARTIAL with a deterministic evidence receipt.

Start free

Run a no-payment MCP endpoint preflight first. It checks reachability, protocol negotiation, tool count and schema issues.

Use in CI or coding agents

If your repository already has an MCP URL, run the free preflight before deploy:

- uses: kaattaallaa-sketch/proofrail-mcp@main
  with:
    target_url: ${{ vars.MCP_URL }}

The Action returns connection, negotiated protocol, tool count and schema issue count. No payment is required.
